🚀 GitHub Pages で無料公開する方法

✨ このコード1つで完全に動くWebアプリです！

ソフトのインストール不要で、GitHubの無料機能を使って世界中に公開できます。

  1. GitHubアカウントを作成（未所持の場合）
    github.com に登録します。
  2. 新しいリポジトリ（Repository）を作成
    「New Repository」をクリックし、名前（例: 3shoku-game）を入力して作成します。
  3. index.html をアップロード
    「uploading an existing file」を選択し、このファイル（名前を index.html にしてください）をドラッグ＆ドロップして「Commit changes」を押します。
  4. GitHub Pages を有効化
    リポジトリの Settings ➔ Pages を開き、Branch を main に設定して 「Save」を押します。
  5. iPadで開いてホーム画面に追加！
    数分後に発行されるURL（例: https://username.github.io/3shoku-game）をiPadのSafariで開きます。「共有」ボタン ➔ 「ホーム画面に追加」でアプリ化できます！
